Concept 1 — The for Loop: Repeating a Known Number of Times
20 mins
💡 Real-World Analogy
Imagine you have a list of 10 friends and you want to text each of them "Happy Birthday." You don't type 10 separate messages — you loop through the list and send the same message to each one. A for loop does exactly that: it runs a block of code once for every item in a sequence.
How it works
A for loop iterates over a sequence — a range of numbers, a list of names, or any collection of items. The loop variable (the thing after for) takes the value of each item one at a time, and the indented block runs for each one.
for_range.py
# Loop 5 times using range()
for i in range(5):
    print(f"Step {i}")

💡 range() explained
range(5) gives you numbers 0, 1, 2, 3, 4 — note it stops before 5, not at 5. This trips up a lot of beginners.

range(1, 6) → 1, 2, 3, 4, 5  |  range(0, 10, 2) → 0, 2, 4, 6, 8 (step of 2)

Concept 2 — The while Loop: Repeating Until a Condition Changes
20 mins
💡 Real-World Analogy
A while loop is like a security guard checking "is the door locked?" over and over. As long as the answer is no, they keep checking. The moment the door is locked, they stop. You use a while loop when you don't know in advance how many times something needs to repeat.
Loop starts
↓
Is condition still True?
↓
YES
Run the loop body
↓
↩ back to check
↓
NO
Exit the loop
while_loop.py
# Reinforces: input(), conditionals, f-strings

def guess_game():
    secret = 7 # LOCAL
    guess = 0 # start value — not the secret

    while guess != secret:
        guess = int(input("Guess the number (1-10): "))
        if guess < secret:
            print("Too low! Try again.")
        elif guess > secret:
            print("Too high! Try again.")

    print(f"🎉 Correct! The number was {secret}.")

guess_game()

⚠️ THE INFINITE LOOP — Most Common while Bug
If the condition never becomes False, the loop runs forever and your program freezes. Always ask: "Is there something inside my loop that will eventually make the condition False?" In the example above, the user typing the correct guess makes guess == secret, which stops the loop.

Concept 3 — break, continue & Loops Inside Functions
20 mins
Beginner Explanation
Sometimes you want to escape a loop early (break) or skip one iteration (continue) without stopping the whole loop. Combined with functions, loops become the engine behind almost every real automation script.
KeywordWhat it doesWhen to use it
break Exits the loop immediately Found what you were looking for, or hit an error condition
continue Skips the rest of this iteration, jumps to next Want to ignore certain items but keep looping
range(start, stop, step) Generates a sequence with full control Counting up, down, or by specific intervals
break_continue.py
# Reinforces: functions, scope, conditionals, f-strings

def find_first_even(limit):
    for n in range(1, limit):
        if n % 2 == 0: # % is "modulo" — remainder after dividing
            print(f"Found first even number: {n}")
            break # stop as soon as we find it

def print_odds_only(limit):
    for n in range(1, limit):
        if n % 2 == 0:
            continue # skip even numbers
        print(f"{n} is odd")

find_first_even(10)
print_odds_only(8)

The Infinite Chatbot Loop
while + for + conditionals + functions — 40 mins
Build a chatbot that keeps running until the user says goodbye — using a while loop as the main engine. It tracks the conversation history with a for loop, and every response comes from a function with conditionals inside. This is a direct preview of how real AI chatbot interfaces work.
chatbot.py
# The Infinite Chatbot Loop — Day 7 Project
# while loop + for loop + functions + conditionals + f-strings

bot_name = "Nova" # GLOBAL
history = [] # stores the conversation (preview of lists!)

def get_response(message):
    msg = message.lower() # LOCAL
    if msg in ["hi", "hello", "hey"]:
        return "Hey! What's on your mind?"
    elif "python" in msg:
        return "Python is awesome — great choice!"
    elif "ai" in msg:
        return "AI is the future — keep building!"
    elif msg in ["bye", "quit", "exit"]:
        return "EXIT" # special signal to stop the loop
    else:
        return "Interesting! Tell me more."

def show_history():
    print("\n--- Conversation History ---")
    for line in history: # for loop over the history list
        print(line)

# --- Main loop ---
print(f"{bot_name}: Hi! I'm {bot_name}. Type 'bye' to exit.\n")

while True: # runs forever until break
    user_input = input("You: ")
    response = get_response(user_input)

    if response == "EXIT":
        print(f"{bot_name}: Goodbye! See you tomorrow. 👋")
        break

    history.append(f"You: {user_input}")
    history.append(f"{bot_name}: {response}")
    print(f"{bot_name}: {response}\n")

show_history()
