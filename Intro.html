Concept 1 — The print() Function
15 mins
Beginner Explanation
Programming is just giving the computer instructions. print() is how we tell the computer to talk back to us — it displays whatever you put inside it onto the screen.
hello.py
# Your very first line of Python!
print("Hello, World!")
Terminal Output
Hello, World!

Concept 2 — Variables & Data Types
25 mins
Beginner Explanation
A variable is a labeled storage box. If you have a box labeled "age" and put 18 inside it, whenever you ask for age, the computer gives you 18. There are different box types for different kinds of data:
Type Name Example Value When to Use
str String "Hello" Text, names, sentences
int Integer 18 Whole numbers (age, count)
float Float 9.99 Decimals (prices, scores)
variables.py
# Create variables for name, age, and hobby
name = "Marcus" # str
age = 18 # int
hobby = "coding" # str
gpa = 3.8 # float

print(name)
print(age)
print(hobby)
Exercise
Create a new file variables.py and write variables for your own name, age, and favourite hobby. Print all three. Then check: can you add two integer variables together?
Concept 3 — The input() Function & f-strings
20 mins
Beginner Explanation
Now let's make our program interactive. input() pauses the program and waits for the user to type something. An f-string lets you stitch variables into text by prefixing your string with f and putting variable names in curly braces {}.
greeter.py
# Ask the user for their name
name = input("What is your name? ")

# Use an f-string to greet them
print(f"Welcome to my first program, {name}!")
Example Terminal Session
What is your name? Marcus
Welcome to my first program, Marcus!
Exercise
Write this script and run it. Then extend it — ask for the user's age too, and print "Nice, you are 18 years old, Marcus!" using an f-string with both variables.
Hour 02
Practical Application & Building in Public
The Story Generator
Mad Libs — 40 mins
Put everything you've learned together. Your script will ask the user for 4 inputs, then use f-strings to build a hilarious story from their answers.
story_generator.py
# Mad Libs Story Generator
# Day 3 Project — Python Learning Journey

print("=== THE STORY GENERATOR ===")
print("Answer the questions to create your story!\n")

# Collect inputs from the user
noun = input("Enter a noun (a person, place, or thing): ")
place = input("Enter a place: ")
adjective = input("Enter an adjective (describing word): ")
verb = input("Enter a verb (action word): ")

# Build and print the story
print("\n--- YOUR STORY ---")
print(f"Yesterday, a {adjective} {noun} went to {place} to {verb}.")
print(f"Everyone at {place} was shocked to see such a {adjective} sight.")
print(f"The {noun} decided to {verb} all day long and never looked back!")
Example Output
=== THE STORY GENERATOR ===
Answer the questions to create your story!

Enter a noun: penguin
Enter a place: Nairobi
Enter an adjective: sparkly
Enter a verb: dance

--- YOUR STORY ---
Yesterday, a sparkly penguin went to Nairobi to dance.
Everyone at Nairobi was shocked to see such a sparkly sight.
The penguin decided to dance all day long and never looked back!
  • Script runs without errors in VS Code terminal
  • All 4 inputs collected with clear prompts
  • Story prints using all 4 variables via f-strings
  • Output is readable and makes logical (or hilariously illogical) sense
  • Code has at least 3 comment lines explaining what it does
