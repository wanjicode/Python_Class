Concept 1 — if / else: Teaching the Computer to Choose
15 mins
💡 Real-World Analogy
Every decision you make is a conditional. "If it's raining, take an umbrella. Otherwise, leave it." That's exactly what Python's if/else does — it checks whether something is true and runs different code depending on the answer.
Is the condition True?
↓
YES
run the if block
↓
NO
run the else block
if_else.py
# Reinforces: input(), f-strings
age = int(input("How old are you? "))

if age >= 18:
    print(f"Welcome! You are {age} — old enough to enter.")
else:
    print(f"Sorry, you are {age} — you must be 18 or older.")
Two possible outputs
How old are you? 20
Welcome! You are 20 — old enough to enter.

How old are you? 15
Sorry, you are 15 — you must be 18 or older.
⚠️ COMMON MISTAKE — = vs ==
A single = assigns a value: age = 18
A double == compares two values: age == 18
Using = inside an if statement is one of the most common beginner bugs. Always use == when checking.

Concept 2 — elif: Handling Multiple Conditions
20 mins
Beginner Explanation
elif is short for "else if" — it lets you check a second (or third, or fourth) condition if the first one was false. Python checks each condition top to bottom and runs the first one that's true, then skips the rest.

# Reinforces: functions, return values, f-strings, input()

def get_grade(score):
    if score >= 90:
        return "A — Excellent!"
    elif score >= 80:
        return "B — Good job!"
    elif score >= 70:
        return "C — You passed."
    elif score >= 60:
        return "D — Just made it."
    else:
        return "F — Study harder!"

# Main program — uses input() and f-string
score = int(input("Enter your score (0-100): "))
result = get_grade(score)
print(f"Your grade: {result}")

Concept 3 — Conditionals Inside Functions (Scope Revisited)
25 mins
Why This Matters
Real programs combine everything. A function can contain conditionals, and those conditionals can use the function's local variables — reinforcing why scope matters. This is also the pattern used in almost every AI automation: receive input → make a decision → return an output.
ai_responder.py
# A tiny taste of what AI automations look like:
# receive input → decide → return a response

bot_name = "PyBot" # GLOBAL variable

def respond(user_input):
    response = "" # LOCAL variable

    if user_input == "hello":
        response = "Hey there! How can I help?"
    elif user_input == "bye":
        response = "Goodbye! Come back soon."
    elif user_input == "help":
        response = "I can respond to: hello, bye, help"
    else:
        response = "I don't understand that yet!"

    return f"{bot_name}: {response}"

# Main loop — input() + f-string
message = input("You: ").lower()
print(respond(message))
Example Terminal Session
You: hello
PyBot: Hey there! How can I help?

You: what is AI
PyBot: I don't understand that yet!
🔥 CONNECT TO THE BIG PICTURE
Point this out to the student explicitly: this is literally how the first chatbots worked — and it's still the decision-making logic inside modern AI systems, just at a much larger scale. The respond() function is a primitive version of what Claude and ChatGPT do. Let that sink in.

The AI Quiz Game
Conditionals + Functions + Everything Before — 40 mins
Build a 3-question quiz where every question is its own function, every answer is checked with conditionals, and the final score triggers a personalised result message. This intentionally uses everything from the last 3 sessions together.
quiz_game.py
# AI Quiz Game — Day 6 Project
# Uses: functions, return, scope, input(), f-strings, conditionals

player_name = input("Enter your name: ") # GLOBAL

def ask_question(question, correct_answer):
    answer = input(f"{question} ").lower() # LOCAL
    if answer == correct_answer:
        print("✓ Correct!\n")
        return 1 # return 1 point
    else:
        print(f"✗ Wrong! The answer was {correct_answer}.\n")
        return 0 # return 0 points

def get_result(score):
    if score == 3:
        return "Perfect score! You're a genius 🧠"
    elif score == 2:
        return "Great job! So close to perfect."
    elif score == 1:
        return "Not bad — keep studying!"
    else:
        return "Better luck next time. You've got this!"

# --- Run the quiz ---
print(f"\nWelcome, {player_name}! Answer these 3 questions.\n")

score = 0
score += ask_question("What language are we learning?", "python")
score += ask_question("What keyword defines a function?", "def")
score += ask_question("What does input() do?", "asks the user for input")

print(f"{player_name}, you scored {score}/3!")
print(get_result(score))
