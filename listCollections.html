Part 01
Understanding Lists
What is a List?
15 mins
💡 Think of it this way
Imagine you're packing a bag for a trip. Instead of carrying each item in a separate hand, you put everything into one bag. A list in Python is that bag — it holds multiple items inside a single variable, in order, so you can carry them all around together.
Up until now, each variable you've created has held one thing — one name, one number, one string. A list lets a single variable hold as many things as you want, all in a specific order. You create a list using square brackets [] with items separated by commas.
lists_intro.py
# A variable holding ONE thing
tool = "Python"

# A list holding MANY things
tools = ["Python", "VS Code", "Git", "GitHub"]

# Lists can hold different types too
mixed = ["Marcus", 18, True, 9.5]

# Check how many items are in a list
print(len(tools)) # → 4
print(len(mixed)) # → 4

indexing.py
skills = ["Python", "Git", "APIs", "AI", "Deploy"]

# Grab specific items by index
print(skills[0]) # → Python (first item)
print(skills[3]) # → AI
print(skills[-1]) # → Deploy (last item)
print(skills[-2]) # → AI (second from last)

# Slicing — grab a chunk of the list
print(skills[1:3]) # → ['Git', 'APIs'] (index 1 up to but NOT 3)
print(skills[:2]) # → ['Python', 'Git'] (from start to index 2)
print(skills[2:]) # → ['APIs', 'AI', 'Deploy'] (from index 2 to end)

# Update an item
skills[2] = "REST APIs"
print(skills)

⚠️ IndexError — The Most Common List Bug
If you try to access an index that doesn't exist — like skills[10] on a 5-item list — Python throws an IndexError. Always remember: a list with 5 items has indices 0 through 4. The last valid index is always len(list) - 1.

Part 02
Looping Through Lists
Lists + Loops — The Most Common Combination in Python
20 mins
In real programs — and in AI automations — you almost always have a list of things to process: a list of messages to analyse, a list of files to read, a list of API results to check. The for loop + list combination is the engine that powers most of that work.
loops_and_lists.py
# Loop through every item in a list
messages = ["hello", "need help", "bye", "what is AI?"]

for msg in messages:
    print(f"Processing: {msg}")

# Loop with enumerate() — get index AND value
for i, msg in enumerate(messages):
    print(f"Message {i+1}: {msg}")

# Build a new list using a loop
urgent = []
for msg in messages:
    if "help" in msg or "bye" in msg:
        urgent.append(msg)

print(f"Priority messages: {urgent}")

The AI Skill Tracker
A personal learning dashboard using lists, loops, functions & conditionals — 40 mins
You're going to build a program that manages your AI engineering learning journey. It will store skills in a list, let you add new ones, mark skills as learned, and show a progress report. This is a real mini-app — and it uses everything you've learned so far.
skill_tracker.py
# AI Skill Tracker — Lists & Collections Project

to_learn = ["Python basics", "APIs", "Prompt engineering", "Automation"]
learned = ["Variables", "Functions", "Conditionals", "Loops"]

def show_progress():
    print("\n=== YOUR AI ENGINEERING PROGRESS ===")
    print(f"\n✅ LEARNED ({len(learned)} skills):")
    for i, skill in enumerate(learned):
        print(f" {i+1}. {skill}")

    print(f"\n📚 STILL TO LEARN ({len(to_learn)} skills):")
    for i, skill in enumerate(to_learn):
        print(f" {i+1}. {skill}")

    total = len(learned) + len(to_learn)
    percent = round((len(learned) / total) * 100)
    print(f"\n🎯 Progress: {percent}% complete")

def mark_learned(skill_name):
    if skill_name in to_learn:
        to_learn.remove(skill_name)
        learned.append(skill_name)
        print(f"✅ '{skill_name}' marked as learned!")
    else:
        print(f"'{skill_name}' not found in your to-learn list.")

def add_skill(skill_name):
    if skill_name not in to_learn and skill_name not in learned:
        to_learn.append(skill_name)
        print(f"📚 '{skill_name}' added to your list!")
    else:
        print("That skill is already on your list.")

# --- Main Menu Loop ---
while True:
    print("\n1. View progress 2. Mark learned 3. Add skill 4. Quit")
    choice = input("Choose: ")

    if choice == "1":
        show_progress()
    elif choice == "2":
        skill = input("Which skill did you learn? ")
        mark_learned(skill)
    elif choice == "3":
        skill = input("What skill do you want to add? ")
        add_skill(skill)
    elif choice == "4":
        print("Keep building! 🚀")
        break
