Part 01
What is a Dictionary?
Lists vs Dictionaries — Knowing Which to Use
15 mins
💡 Think of it this way
A list is like a numbered queue — item 0, item 1, item 2. You find things by their position. A dictionary is like a real dictionary — you look things up by their name (the key), and get back the definition (the value). Instead of person[0] to get a name, you write person["name"]. Much more readable, and far more powerful.

dict_intro.py
# Create a dictionary with curly braces {}
student = {
    "name": "Marcus",
    "age": 18,
    "city": "Nairobi",
    "goal": "AI Engineer"
}

# Access values by their KEY — not by position
print(student["name"]) # → Marcus
print(student["goal"]) # → AI Engineer

# Use f-strings to build readable output
print(f"Name: {student['name']}, Age: {student['age']}, Goal: {student['goal']}")

# Check how many key-value pairs
print(len(student)) # → 4

⚠️ KeyError — The Dictionary Version of IndexError
If you try to access a key that doesn't exist — like student["phone"] when there's no "phone" key — Python throws a KeyError. Later you'll learn to use .get() to handle this safely. For now, always make sure the key exists before accessing it.

Adding, Updating & Removing — Changing a Dictionary
20 mins
Dictionaries are mutable — that means you can change them after they're created. You can add new keys, update existing values, and remove keys you no longer need. This is important because in real programs, data is always changing — a user updates their profile, an AI response adds new fields, a config file gets a new setting.
dict_update.py
profile = {
    "name": "Marcus",
    "skills": 4,
    "active": True
}

# Add a NEW key
profile["city"] = "Nairobi"
print(profile)

# Update an EXISTING key
profile["skills"] = 5 # just learned Lists!
print(profile["skills"])

# Remove a key safely with .pop()
removed = profile.pop("active")
print(f"Removed: {removed}")
print(profile)

# Check if a key exists before accessing it
if "city" in profile:
    print(f"City found: {profile['city']}")

# .get() — safe access with a default fallback
print(profile.get("phone", "No phone listed"))
Output
{'name': 'Marcus', 'skills': 4, 'active': True, 'city': 'Nairobi'}
5
Removed: True
{'name': 'Marcus', 'skills': 5, 'city': 'Nairobi'}
City found: Nairobi
No phone listed
💡 Always Use .get() When You're Not Sure a Key Exists
.get("key", default) returns the value if the key exists, or the default if it doesn't — without crashing your program. When you start working with AI API responses, some keys will be optional and won't always be there. .get() will save you constantly.

Looping & Methods — Working Through a Dictionary
25 mins
Just like lists, you'll often need to loop through a dictionary — through its keys, its values, or both at the same time. Python gives you three methods for this: .keys(), .values(), and .items(). The last one is the most useful — it gives you both the key and value together on every iteration.
MethodWhat it gives youWhen to use it
.keys()All the keysWhen you only need to know what fields exist
.values()All the valuesWhen you only need the data, not the labels
.items()Key-value pairs as tuplesMost of the time — gives you everything
.get(k, default)Value or safe fallbackWhen a key might not exist
.update(dict2)Merges another dict inWhen combining two data sources
inTrue if key existsBefore accessing an uncertain key
dict_loops.py
ai_tools = {
    "ChatGPT": "OpenAI",
    "Claude": "Anthropic",
    "Gemini": "Google",
    "Copilot": "Microsoft"
}

# Loop through keys only
print("AI Tools:")
for tool in ai_tools.keys():
    print(f" - {tool}")

# Loop through key-value pairs — the most useful
print("\nTool → Company:")
for tool, company in ai_tools.items():
    print(f" {tool} is made by {company}")

# Combine with a conditional
for tool, company in ai_tools.items():
    if company == "Anthropic":
        print(f"\n{tool} is the one we'll use to build AI apps!")

Part 02
Nested Dictionaries — Dicts Inside Dicts
Real-World Data is Always Nested
20 mins
In the real world, data is rarely flat. A user doesn't just have a name — they have a name, an address with a street and city, a list of skills, and a settings object. This is called nested data — dictionaries inside dictionaries. It's also exactly how AI API responses are structured. Learning to read nested data now will make working with APIs feel natural when we get there.
nested_dicts.py
# A nested dictionary — dict inside a dict
user = {
    "name": "Marcus",
    "location": {
        "city": "Nairobi",
        "country": "Kenya"
    },
    "skills": ["Python", "Git", "Functions", "Loops", "Lists"],
    "stats": {
        "days_coded": 11,
        "projects_built": 6
    }
}

# Access nested values by chaining keys
print(user["name"])
print(user["location"]["city"])
print(user["stats"]["days_coded"])
print(user["skills"][0]) # first skill in the list

# Loop through the skills list inside the dict
print("\nSkills learned so far:")
for skill in user["skills"]:
    print(f" ✅ {skill}")

# Build a summary with f-strings
print(f"\n{user['name']} from {user['location']['city']} has coded for {user['stats']['days_coded']} days!")

The AI Chatbot Contact Book
A dictionary-powered app that manages AI tools and their details — 40 mins
You're building a contact book — but instead of people, you're storing AI tools. Each tool has nested details: the company that made it, what it's used for, whether you've tried it, and a rating. You'll be able to view all tools, look up a specific one, add new ones, and update your ratings. This is a real data management app built entirely with dictionaries, loops, and functions.
ai_contact_book.py
# AI Tool Contact Book — Dictionaries Project

ai_tools = {
    "Claude": {
        "company": "Anthropic",
        "use_case": "Coding, writing, reasoning",
        "tried": True,
        "rating": 5
    },
    "ChatGPT": {
        "company": "OpenAI",
        "use_case": "General purpose AI assistant",
        "tried": True,
        "rating": 4
    },
    "Gemini": {
        "company": "Google",
        "use_case": "Search, multimodal tasks",
        "tried": False,
        "rating": None
    }
}

def show_all():
    print("\n=== ALL AI TOOLS ===")
    for name, details in ai_tools.items():
        tried_str = "✅ Tried" if details["tried"] else "⬜ Not yet"
        print(f"\n {name} ({details['company']}) — {tried_str}")
        print(f" Use: {details['use_case']}")
        if details["rating"]:
            print(f" Rating: {'⭐' * details['rating']}")

def lookup_tool(name):
    tool = ai_tools.get(name)
    if tool:
        print(f"\n{name}: {tool}")
    else:
        print(f"'{name}' not found. Try adding it!")

def add_tool():
    name = input("Tool name: ")
    company = input("Company: ")
    use_case = input("Use case: ")
    ai_tools[name] = {
        "company": company,
        "use_case": use_case,
        "tried": False,
        "rating": None
    }
    print(f"✅ '{name}' added!")

# --- Main Menu ---
while True:
    print("\n1. View all 2. Look up 3. Add tool 4. Quit")
    choice = input("Choose: ")
    if choice == "1": show_all()
    elif choice == "2": lookup_tool(input("Tool name: "))
    elif choice == "3": add_tool()
    elif choice == "4": print("Keep building! 🚀"); break
